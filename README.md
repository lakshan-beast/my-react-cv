
# 📄 Interactive React Portfolio CV & Print Engine

An advanced, conversion-optimized, and highly responsive interactive web application built with React.js and SASS [INDEX 4]. This application functions as a live digital portfolio web page while dynamically transforming into a clean, professional, print-ready A4 PDF CV using specialized @media print styling rules.

🟢 Live Preview: [your-project-name.vercel.app](https://vercel.app)

---

## ✨ Features

- Neon Cyber Theme: Styled with a modern, high-contrast #00ff88 tech/cybersecurity theme.
- Dynamic Print Engine: Pressing Ctrl + P or clicking the "Print CV" button triggers a fully stripped, high-contrast, black-and-white A4 layout optimized for recruiters.
- Dynamic URL Printing: Hyperlinks automatically render their full readable URLs on the printed document using SASS pseudo-elements.
- Professional Categorization: Structured layout highlighting Frontend Architecture, Security Compliance layers, Tools, and Personal Interests (Chess, Ethical Hacking) [INDEX 4].

## 🛠️ Tech Stack & Utilities

- Core Frontend: React.js, SASS / SCSS (Variables, Mixins), JavaScript (ES6+), HTML5, CSS3 [INDEX 4]
- Libraries: Recharts (Analytics capability)
- Platforms & Tooling: Vite, Vercel, Netlify, VS Code, Git, npm, Chrome DevTools
- AI-Optimized Workflow: Developed leveraging Cursor AI and Claude AI workflows

## 🚀 Getting Started Locally

Follow these steps to run the project on your local machine:

### 1. Clone the repository

git clone https://github.com
cd your-repo-name

### 2. Install dependencies (including SASS)

npm install

### 3. Start the local development server

npm run dev
Open your browser and navigate to http://localhost:5173.
