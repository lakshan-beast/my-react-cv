
# 📄 Interactive React Portfolio CV & Print Engine

An advanced, conversion-optimized, and highly responsive interactive web application built with React.js, TypeScript and TaildwindCSS. This application functions as a live digital portfolio web page while dynamically transforming into a clean, professional, print-ready A4 PDF CV using specialized @media print styling rules.

🟢 Live Preview: [(https://lakshan-sandeepa-cv.vercel.app/)](https://lakshan-sandeepa-cv.vercel.app/)

---

## ✨ Features

- Neon Cyber Theme: Styled with a modern, high-contrast #00ff88 tech/cybersecurity theme.
- Dynamic Print Engine: Pressing Ctrl + P or clicking the "Print CV" button triggers a fully stripped, high-contrast, black-and-white A4 layout optimized for recruiters.
- Dynamic URL Printing: Hyperlinks automatically render their full readable URLs on the printed document using SASS pseudo-elements.
- Professional Categorization: Structured layout highlighting Frontend Architecture, Security Compliance layers, Tools, and Personal Interests (Chess, Ethical Hacking).

## 🛠️ Tech Stack & Utilities

- Core Frontend: React.js,taildwindCSS, SASS / SCSS (Variables, Mixins), JavaScript (ES6+), TypeSript, HTML5, CSS3
- Libraries: Recharts (Analytics capability)
- Platforms & Tooling: Vite, Vercel, Netlify, VS Code, Git, npm, Chrome DevTools
- AI-Optimized Workflow: Developed leveraging Cursor AI and Claude AI workflows
